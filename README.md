# 後端模組

## 專案概述
此模組是 AI 虛擬社群平台的後端部分，使用 **Spring Boot** 開發，負責處理用戶請求、文章發佈、生成 AI 回應的請求，以及與資料庫的交互。該平台的重點是提供情感支持，通過 AI 生成的個性化回應來增強用戶互動的深度。

## 技術棧
- **Spring Boot**: Java 後端框架，用於構建 RESTful API 和管理依賴。
- **MySQL**: 用於數據存儲，保障用戶數據和文章信息的持久性。
- **Spring Security**: 用於用戶認證和授權，確保 API 端點的安全性，防止未授權訪問。
- **Hibernate**: ORM 框架，負責將 Java 對象映射到數據庫表，減少手動撰寫 SQL 查詢的需求。

## 主要功能
- **用戶管理**：處理註冊、登入、身份驗證。
- **文章管理**：處理文章的創建、更新和刪除。
- **AI 回應管理**：利用 prompt 工程技術生成 AI 回應，處理用戶提交的請求，並將結果返回給前端。這樣能夠靈活地生成個性化的情感回應。
- **情感日誌管理**：用戶可以提交每日的情感日誌，後端進行存儲。

## API路由
POST /api/auth/signup: 註冊新用戶。 (公開)
POST /api/auth/login: 用戶登入，生成授權 Token。 (公開)
POST /api/articles: 創建新文章。（需要身份驗證）
GET /api/articles: 獲取所有文章。（公開，可根據權限控制某些文章的可見性）
POST /api/ai-response: 請求 AI 生成回應。（需要身份驗證）


## 文件結構
/src/main/java: 包含所有Java代碼。
/controller: 定義 API 控制器，負責處理客戶端的請求並返回相應的結果。
/service: 處理業務邏輯，包含所有的服務方法，如用戶管理、文章處理和 AI 回應生成。
/repository: 與數據庫的交互，使用 Hibernate 來進行 CRUD 操作。
/model: 定義數據庫實體類，映射到數據庫表的 Java 類。
